## 👋 About me

ジャンルを固定せず、**「これ作ってみたい」から始めて、実際に動くところまで持っていく**個人開発者です。

そのとき必要なもの・面白そうなものに合わせて、言語やフレームワーク、実行環境まで選びます。
Botを作ったと思ったらWebを作り、Webを作ったと思ったらデスクトップアプリや言語処理系を作っている、そんな感じです。
