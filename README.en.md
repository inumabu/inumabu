## 🚀 Projects

**These are the main public projects I'm currently working on or maintaining.**

### 🌙 yanagi
A Discord Bot Ecosystem foundation with separate API, bot, TTS, dashboard, and operations layers.

→ https://github.com/inumabu/yanagi

### 🤖 mabubot
A feature-rich Discord community bot covering AI, economy, games, events, moderation, voice, and more.

→ https://github.com/inumabu/mabubot

### 🧠 mojule
A modular AI agent for combining knowledge, capabilities, and reasoning, with recipes, run history, async jobs, and authentication/RBAC.

→ https://github.com/inumabu/mojule

### 🚀 touwa-editor
A desktop code editor foundation built with Electron, React, TypeScript, and Monaco Editor, targeting Windows first.

→ https://github.com/inumabu/touwa-editor

### ☕ java-learning-support
A Java learning support website skeleton built with Java 21, Spring Boot, Thymeleaf, and Oracle Database.

→ https://github.com/inumabu/java-learning-support

### 🔊 yomiage
A Discord bot that reads channel messages aloud with VOICEVOX, including queue and voice-control features.

→ https://github.com/inumabu/yomiage

### 🎲 asobibot
A lightweight Discord bot for omikuji, dice, rock-paper-scissors, and four-choice quizzes.

→ https://github.com/inumabu/asobibot

### 🧰 kokoneads
A browser-focused developer tool site for working with JSON, text, URLs, Markdown, and related data.

→ https://github.com/inumabu/kokoneads

### 🍅 aurorasauce
A small educational programming language implementation themed around aurora sauce. Currently in pre-alpha.

→ https://github.com/inumabu/aurorasauce
